Vinayaka Works - STATIC WEBSITE TEMPLATE

Pages and files:
- index.html       Home and Contact sections
- contracts.html  Separate Contracts / Projects page
- css/style.css   Shared styling
- js/script.js    Mobile navigation, project filters and WhatsApp enquiry
- images/         Folder for your own images

How to run:
1. Extract the ZIP.
2. Open the construction-website folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Click Contracts in the navigation bar to open contracts.html.

Before publishing, edit:
- Company name and logo in both HTML pages
- Phone and WhatsApp number in both HTML pages and js/script.js
- Email and location in index.html
- Experience and project statistics in index.html
- Project photos and descriptions in contracts.html
- Sample image URLs if you want to use your own local images

Note:
This is a static front-end website. The enquiry form opens WhatsApp with a pre-filled message; it does not store submissions in a database. Google Fonts and sample Unsplash photos require an internet connection.
